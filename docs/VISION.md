# PokeJuz — Visión del ecosistema

**Estado:** dirección estratégica acordada; no es una promesa de fechas o funciones terminadas. **Actualización:** 2026-11-04.

## Principio

> El usuario decide qué quiere hacer; la complejidad debe resolverla la herramienta.

PokeJuz reúne herramientas independientes, gratuitas y de uso sencillo para personalizar, jugar, registrar y compartir desafíos de Pokémon. No distribuye ROMs ni archivos extraídos de juegos.

## Productos y responsabilidades

- **Definitive Randomizer:** edición, randomización, mejoras de jugabilidad y, más adelante, perfiles y edición visual DS.
- **Progressive Tracker (NuzlockeTracker):** seguimiento Nuzlocke y Soul Link, conexión a emuladores, OBS y datos precisos de juegos modificados.
- **Definitive Hub (concepto):** biblioteca comunitaria de perfiles reutilizables, importación, comparación y compatibilidad verificable.
- **PokeJuz:** web y fuente principal de visión, roadmap y comunicación de los proyectos. Los repositorios de cada aplicación mantienen su código, incidencias y releases.

## Principios de producto

1. La seguridad de los datos, la reversibilidad y el respaldo son prioritarios.
2. Las funciones deben explicar compatibilidad y fallos de forma comprensible.
3. La simplicidad por defecto no elimina las opciones avanzadas.
4. Las aplicaciones deben funcionar de forma independiente y poder intercambiar datos mediante contratos versionados.
5. Los perfiles y modificaciones compartidos deben identificar autores, versiones, procedencia y restricciones de distribución.
6. Todo el software principal seguirá siendo gratuito; las donaciones serán voluntarias y no habrá anuncios invasivos ni bloqueo de funciones esenciales.

## Comunidad y alcance

El contenido público principal será **en español**, empezando por YouTube, documentación y demostraciones de uso. Se podrán añadir subtítulos en inglés. Ko-fi y, si se habilita, GitHub Sponsors servirán para apoyar voluntariamente el desarrollo.

El roadmap indica direcciones e investigación. Una función solo pasa a «en desarrollo» cuando se delimita el alcance y se preparan criterios de aceptación.
